# 项目路径与协作规范

> 本规范是全体成员唯一遵循的路径与协作约定。任何代码、脚本、文档若与本规范冲突，以本规范为准。

## 1. 仓库信息

- 仓库地址：https://github.com/yingh777706/shanghai-metro-viz.git
- 默认分支：`main`
- 编码：Python 源码 UTF-8；CSV 输出 `utf-8-sig`（Excel 可直接打开）

## 2. 目录结构（唯一事实来源）


## 3. 路径三条铁律

1. **禁止硬编码绝对路径**。数据文件一律用 `common.find_data(name)` 解析；任何输出目录一律基于 `common.PROJECT_ROOT` 拼接。历史遗留的 `C:\Users\xxx\Desktop\...` 之类一律整改。（本铁律约束**已入库**的脚本；不入库的脚本——如分工1 清洗脚本——不受约束，见分工1 任务清单。）
2. **运行即交付**。每个脚本的输出直接写到本分工的 `分工N_*/` 目录，**废弃 `输出结果/` 中间目录**。重跑脚本 = 更新交付物，二者永不漂移。
3. **统一 import 方式**。`code/分工N/` 下的脚本按下面模板 import 公共模块：

   ```python
   import sys
   from pathlib import Path
   sys.path.insert(0, str(Path(__file__).resolve().parent.parent))  # 指向 code/
   from common import PROJECT_ROOT, find_data
   ```

## 4. 数据文件查找顺序

`common.find_data()` 已实现，按以下优先级查找（存在即返回）：

`METRO_DATA_DIR 环境变量` > `data/` > `processed_data/` > `docs/processed_data/` > `docs/data/`

> 找不到时抛 FileNotFoundError 并列出全部已搜索路径；可设 `METRO_DATA_DIR` 指向任意数据目录。

## 5. 命名与输出规范

- 表：`表N_名称.csv`（`utf-8-sig`）；图：`图N_名称.png`（≥150 DPI）；结论：`XX分析结论.md`
- 各分工说明文档统一为 `分工N_*/README.md`（放在本分工交付目录内）

## 6. 数据口径统一（重要）

- 「客运量」统一以 **进站量（inFlow）** 口径统计；若用「进出站合计」必须显式标注。
- 时间范围统一 `2017-05-01 ~ 2017-08-31`，运营时段 `06:00~22:00`。
- 异常日（20170504 等 6 天刷卡近乎缺失）需在报告/图注中说明处理方式（见分工4 `viz_style.ABNORMAL_DATES`）。

## 7. 提交规范

- 提交前自检：`python -m py_compile <改动文件>` 通过。
- 不提交：`data/`、`__pycache__/`、`*.pyc`、以及任何 >1MB 的中间 CSV（走网盘/压缩包分发）。
- Commit message 格式：`分工N: <动词> <描述>`（例：`分工2: 修 OUT_DIR 指向 分工2_统计分析`）。
- 只改自己分工的目录；跨分工改动需在 commit message 里说明原因。
