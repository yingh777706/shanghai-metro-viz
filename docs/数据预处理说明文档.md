# MetroFlow数据集预处理说明文档
## 1.数据源说明
原始数据集来源：Figshare MetroFlow上海地铁刷卡数据集
辅助数据集：站点属性表、小时天气数据集、工作日日历表

原始数据存放目录：raw_data
清洗后共享数据集目录：processed_data

## 2.处理时间范围
- 全局时间区间：2017‑05‑01 ~ 2017‑08‑31
- 每日运营时段：06:00‑23:00，剔除凌晨非运营时段数据

## 3.数据处理与清洗规则
1. 时间处理：原始date字段、startTime字段拼接生成标准datetime时间戳，统一为10分钟时间粒度
2. 进出站流量表(std_10min_inout.csv)
- 过滤inFlow、outFlow小于0的异常流量记录
- 仅保留stationID存在于站点信息表内的有效站点，剔除无效站点ID
3. OD出行表(std_10min_od.csv)
- 剔除originStation == destinationStation同站出行无效记录
- 过滤Flow小于0负流量异常记录
4. 元数据处理
- station_info.csv：站点ID去重，校验经纬度
- weather_hourly.csv：校验气象字段合法性
- workday_calendar.csv：日期与工作日标记

## 4.输出数据集字段说明
### std_10min_inout.csv 10分钟粒度站点进出站客流
date,timeslot,startTime,endTime,stationID,inFlow,outFlow,CinFlow,HB0inFlow,NHBinFlow,CoutFlow,HB0outFlow,NHBoutFlow,datetime

### std_10min_od.csv 10分钟粒度OD出行客流
date,timeslot,startTime,endTime,originStation,destinationStation,Flow,CFlow,HBOflow,NHBFlow,datetime

### station_info.csv站点信息
stationID,name,lon,lat,neighbour

### weather_hourly.csv小时天气
date,temperature_2m,apparent_temperature,rain,wind_speed_10m

### workday_calendar.csv工作日标记
date,isWorkday

## 5.使用注意事项
1. processed_data为**完成基础清洗的中间数据集，尚未做特征工程**；做预测模型任务需要自行构造小时、星期、滞后客流等特征。
2. std_10min_od.csv文件体积巨大，不建议微信QQ直接传输；建议压缩包、网盘分发。
3. data_check.py为校验脚本，用于验证数据集质量：校验时间范围、流量非负、OD同站记录是否清零。
4. raw_data保存原始文件，请勿修改删除，方便复现。

## 6.质量校验结果
- 进出站最小inFlow=0，最小outFlow=0，无负流量
- OD抽样校验：起终点相同记录=0，最小Flow=1，无负流量
