# 上海地铁数据可视化

基于 2017 年 5–8 月上海地铁刷卡数据集的客流分析与可视化项目（《软件开发实践1》课程项目）。

## 项目简介

地铁系统在城市出行中的作用日益重要。本项目基于上海地铁刷卡数据集（302 个地铁站、超 7 亿条智能卡刷卡记录，附站点属性与天气等辅助信息），通过数据预处理、统计分析、地图可视化等方式，计算描述性统计特征，分析客流时空规律，可视化呈现乘客出行模式，并可进一步采用聚类、预测等算法进行深度挖掘。

## 数据来源

- 数据集：<https://github.com/Ariza-Sun/MetroFlow>
- 参考论文：Sun P, Yang J, Huang Z, et al. *Human mobility datasets in the complex metro system of Shanghai*. Scientific Data, 2025, 12(1): 1061.

## 数据工程（分工1）

> 原《数据预处理说明文档》与《清洗运行日志》已总并入本节。

**数据源**：Figshare MetroFlow 上海地铁刷卡数据集（原始文件存 `raw_data/`，
清洗后存 `processed_data/`），辅助数据为站点属性表、小时天气、工作日日历。
时间范围 2017-05-01 ~ 2017-08-31，每日运营时段 06:00–23:00（剔除凌晨非运营数据）。

**清洗规则**：

1. 时间处理：`date` + `startTime` 拼接为标准 datetime，统一 10 分钟粒度；
2. 进出站表：过滤 `inFlow`/`outFlow` < 0 的异常记录，仅保留站点信息表内的有效站点；
3. OD 出行表：剔除同站出行（`originStation == destinationStation`）与负流量记录；
4. 元数据：站点表去重并校验经纬度，天气表校验字段合法性，日历表核对工作日标记。

**输出数据表**：

| 表 | 关键字段 |
| --- | --- |
| `std_10min_inout.csv` | date, timeslot, startTime, endTime, stationID, inFlow/outFlow, C/HBO/NHB 分类流量 |
| `std_10min_od.csv` | date, timeslot, originStation, destinationStation, Flow, C/HBO/NHB 分类流量 |
| `station_info.csv` | stationID, name, lon, lat, neighbour |
| `weather_hourly.csv` | date, temperature_2m, apparent_temperature, rain, wind_speed_10m |
| `workday_calendar.csv` | date, isWorkday |

**质量校验结果**（26.7 亿行 OD、378.9 万行进出站全部通过）：
进出站与 OD 流量最小值 0/1，无负流量；OD 抽样同站记录为 0；
时间范围 2017-05-01 06:00 ~ 2017-08-31 22:50。

**口径与使用注意**（全体分析脚本适用）：

- 源数据有 6 个异常日（20170504、20170508、20170509、20170616、20170627、20170628）
  刷卡记录近乎缺失，计算日均/占比时统一剔除（`viz_style.ABNORMAL_DATES`）；
- `timeslot` 为跨天全局编号（每天 102 个 10 分钟槽连续累加），日内时段分析需用
  `startTime` 换算；
- 「出行距离」为 OD 起终点经纬度球面直线距离（非轨道路径）；数据集不含行程级
  进出站时刻，「出行时长」为分工1 `od_travel_time.csv` 的模型估算值；
- 换乘站客流按线路汇总时存在归属口径问题，可用「平分到各线」或「单线站 + 换乘站
  单列」处理；
- `std_10min_od.csv` 约 12 GB，请用压缩包/网盘分发，勿直接传输。

## 使用说明

> 全员遵守 `docs/项目路径与协作规范.md`：数据一律经 `common.find_data()` 定位（禁止硬编码绝对路径），
> 脚本输出直接写入各分工交付目录（运行即交付）。

### 1. K-Means 站点聚类（分工5）

```bash
python code/分工5/kmeans_station_clustering.py     # 约 1~3 分钟
```

提取 302 个站点的分时客流特征（工作日/周末 × 17 运营小时 × 进出站，log1p+标准化），
肘部法则+轮廓系数确定 K，最终聚为 5 类站点：
**综合枢纽站 / 就业办公站 / 通勤居住站 / 休闲商圈站 / 郊区低频站点**。

### 2. ARIMA/SARIMA 短时客流预测（分工5）

```bash
python code/分工5/arima_station_forecast.py        # 约 5~15 分钟
```

对典型站点（人民广场·枢纽、莘庄·通勤）的小时级进站客流：
ADF 平稳性检验 → AIC 网格定阶 → 普通 ARIMA 与季节 SARIMA(s=17) 对比 →
预留最后 7 天做样本外检验，输出 MAE / MSE / RMSE / MAPE 与预测对比曲线。

## 分工5 成果速览

- **站点聚类**：302 个站点分为 5 类——综合枢纽 26 站（人民广场、上海火车站等）、
  就业办公 75 站、通勤居住 98 站、休闲商圈 79 站（迪士尼、中华艺术宫等）、
  郊区低频 24 站；K=5 轮廓系数 0.307。
- **方法论证**：K-Means / GMM / Ward 层次聚类三方法在 K=3~8 上对比，统计最优
  均为 K=3；K=5 处 K-Means（0.307）与 GMM（0.312）持平且高于 Ward（0.268），
  说明 5 类口径与 K-Means 选型稳健（详见 `分工5_数据挖掘/聚类/聚类方法对比结论.md`）。
- **短时预测**：SARIMA(1,0,2)×(1,1,1,17) 相比普通 ARIMA，人民广场 MAE
  由 2185 降至 1204 人次/小时（下降约 45%），预测曲线峰形与相位基本同步。
