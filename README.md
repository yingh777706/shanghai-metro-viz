# 上海地铁客流数据分析与可视化

基于 2017 年 5–8 月上海地铁刷卡数据集（MetroFlow）的客流分析与可视化项目（《软件开发实践1》课程小组项目）。

## 1. 项目简介

本项目试图用数据回答一组关于上海地铁的问题：

- 全网客流有多大？哪些站、哪条线最忙？
- 一天中的客流高峰出现在什么时候？工作日和周末有什么不同？
- 302 个地铁站在客流特征上可以分为哪几类？
- 未来几小时的站点客流能否预测？预测效果如何？

全组按「数据 → 统计 → 可视化 → 挖掘」的流水线分成五个分工：

| 流水线角色 | 分工 | 产出形式 |
| --- | --- | --- |
| 清洗数据（全组共用输入） | 分工1 数据工程 | 标准化数据表（不入库） |
| 统计规律 | 分工2 业务分析 | 统计表 + 结论 |
| 地图呈现 | 分工3 空间可视化 | 热力图、OD 流向图、交互地图 |
| 标准图表 | 分工4 统计可视化 | 图 4-1~4-14 |
| 算法挖掘 + 总装 | 分工5 数据挖掘与总装 | 聚类/预测结果、报告、PPT |

> **第一次看本仓库？** 建议阅读顺序：先读本节和第 3、4 节了解全貌 → 再看第 7~10 节各分工的「主要结论」→ 想动手复现直接跳到第 5 节。

## 6. 分工1｜数据工程（pzq）

把 MetroFlow 原始刷卡数据清洗成全组共用的标准化数据集——**其余四个分工的所有脚本都以它的输出为输入**。

> 原《数据预处理说明文档》与《清洗运行日志》已总并入本节。

### 6.1 数据源与清洗规则

**数据源**：Figshare MetroFlow 上海地铁刷卡数据集（原始文件存 `raw_data/`，清洗后存 `processed_data/`），辅助数据为站点属性表、小时天气、工作日日历。
时间范围 2017-05-01 ~ 2017-08-31，每日运营时段 06:00–23:00（剔除凌晨非运营数据）。

**清洗规则**：

1. 时间处理：`date` + `startTime` 拼接为标准 datetime，统一 10 分钟粒度；
2. 进出站表：过滤 `inFlow`/`outFlow` < 0 的异常记录，仅保留站点信息表内的有效站点；
3. OD 出行表（OD 指一次行程的「起点站—终点站」对）：剔除同站出行（`originStation == destinationStation`）与负流量记录；
4. 元数据：站点表去重并校验经纬度，天气表校验字段合法性，日历表核对工作日标记。

### 6.2 输出数据表

| 表 | 关键字段 |
| --- | --- |
| `std_10min_inout.csv` | date, timeslot, startTime, endTime, stationID, inFlow/outFlow, C/HBO/NHB 分类流量 |
| `std_10min_od.csv` | date, timeslot, originStation, destinationStation, Flow, C/HBO/NHB 分类流量 |
| `station_info.csv` | stationID, name, lon, lat, neighbour |
| `weather_hourly.csv` | date, temperature_2m, apparent_temperature, rain, wind_speed_10m |
| `workday_calendar.csv` | date, isWorkday |

### 6.3 质量校验结果

26.7 亿行 OD、378.9 万行进出站全部通过：进出站与 OD 流量最小值 0/1，无负流量；OD 抽样同站记录为 0；时间范围 2017-05-01 06:00 ~ 2017-08-31 22:50。

### 6.4 口径与使用注意（全组分析脚本适用）

- 源数据有 6 个异常日（20170504、20170508、20170509、20170616、20170627、20170628）刷卡记录近乎缺失，计算日均/占比时统一剔除（`viz_style.ABNORMAL_DATES`）；
- `timeslot` 为跨天全局编号（每天 102 个 10 分钟槽连续累加），日内时段分析需用 `startTime` 换算；
- 「出行距离」为 OD 起终点经纬度球面直线距离（非轨道路径）；数据集不含行程级进出站时刻，「出行时长」为分工1 `od_travel_time.csv` 的模型估算值（详见 `docs/dataset_manifest.md`）；
- 换乘站客流按线路汇总时存在归属口径问题，可用「平分到各线」或「单线站 + 换乘站单列」处理；
- `std_10min_od.csv` 约 12 GB，请用压缩包/网盘分发，勿直接传输。

## 7. 分工2｜业务分析（hy）

基于分工1 的标准化数据，统计全网客流的时空规律：总量、时间波动、空间分布、线路强度、出行距离与时长。

### 7.1 运行方式与产出

```bash
python code/分工2/statistical_analysis.py
```

结果输出到 `分工2_统计分析/`：表1~表9（含表8b）统计表，结论详见 `分工2_统计分析/统计分析结论.md`。

### 7.2 主要结论

- **全局**：统计 123 天（2017-05-01 ~ 08-31），总进站量 7.29 亿人次，日均 592.6 万。
- **时间**：工作日日均 651.1 万 vs 周末 451.0 万；早高峰 8:00、晚高峰 17:00。
- **空间**：进站量 Top3 People's Square（人民广场，1800 万）> Xujiahui（徐家汇，1194 万）> Jing'an Temple（静安寺，1189 万）。
- **出行距离**：加权平均直线距离 16.06 km（起终点站经纬度球面距离，非轨道路径）。
- **线路与城区（分工1 补充数据后新增）**：最繁忙线路 Line 2（沿线单站日均进站 27,411 人次）；核心城区客流强度显著高于郊区（以距人民广场 15 km 为界）；加权平均出行时长 44.73 分钟、平均换乘 2.05 次（模型估算，见表7~表9）。

- **主要结论**：工作日全网日均客流约 1300 万人次（进出站合计），周末约为工作日七成；早高峰通勤(C)出行占进站约 36%，周末降至约 16%；人民广场全期进出站合计约 3500 万人次。
- **补充分工1 新数据后的新结论（图4-9~4-14）**：工作日早高峰（07:00–09:00）强于晚高峰（17:00–19:00），周末为午后平缓单峰；仅 13.7% 的客流同线直达，平均网络路径距离约 20.1 km；2 号线日均约 171 万人次居首，郊区线路（5、16 号线）不足其 1/3；早高峰外环外站点进站占比 67.8%（进站为主），内环内仅 36.7%（出站为主）；雨天工作日客流中位数约低 2%，气温每升高 1°C 工作日客流约降 3.9 万人次；周五为一周峰值（日均约 1447 万人次），周日最低。

## 10. 分工5｜数据挖掘与总装（ycl）

用算法做深度挖掘：站点聚类、聚类方法对比论证、短时客流预测；并负责报告与 PPT 的整合交付（`报告/`）。

### 10.1 K-Means 站点聚类

```bash
python code/分工5/kmeans_station_clustering.py     # 约 1~3 分钟
```

提取 302 个站点的分时客流特征（工作日/周末 × 17 运营小时 × 进出站，log1p+标准化），肘部法则+轮廓系数确定 K，最终聚为 5 类站点：**综合枢纽站 / 就业办公站 / 通勤居住站 / 休闲商圈站 / 郊区低频站点**。

### 10.2 聚类方法对比论证

```bash
python code/分工5/cluster_method_comparison.py
```

K-Means / GMM / Ward 层次聚类三方法在 K=3~8 上对比，统计最优均为 K=3；K=5 处 K-Means（0.307）与 GMM（0.312）持平且高于 Ward（0.268），说明 5 类口径与 K-Means 选型稳健（详见 `分工5_数据挖掘/聚类/聚类方法对比结论.md`）。

### 10.3 ARIMA/SARIMA 短时客流预测

```bash
python code/分工5/arima_station_forecast.py        # 约 5~15 分钟
```

对典型站点（人民广场·枢纽、莘庄·通勤）的小时级进站客流：ADF 平稳性检验 → AIC 网格定阶 → 普通 ARIMA 与季节 SARIMA(s=17) 对比 → 预留最后 7 天做样本外检验，输出 MAE / MSE / RMSE / MAPE 与预测对比曲线。

### 10.4 主要结论

- **站点聚类**：302 个站点分为 5 类——综合枢纽 26 站（人民广场、上海火车站等）、就业办公 75 站、通勤居住 98 站、休闲商圈 79 站（迪士尼、中华艺术宫等）、郊区低频 24 站；K=5 轮廓系数 0.307。
- **短时预测**：SARIMA(1,0,2)×(1,1,1,17) 相比普通 ARIMA，人民广场 MAE 由 2185 降至 1204 人次/小时（下降约 45%），预测曲线峰形与相位基本同步。
