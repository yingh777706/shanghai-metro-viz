# 上海地铁客流空间分布与出行模式可视化研究报告

——基于2017年5–8月上海地铁刷卡数据的空间可视化分析

**分工**：空间可视化（分工3）
**成员**：吕可珊（lks）
**课程**：软件开发实践1

---

## 摘要

本报告基于2017年5月至8月上海地铁智能卡刷卡数据集（涵盖302个地铁站、超过7亿条刷卡记录），从空间可视化视角对上海地铁客流的时空分布特征与乘客出行模式进行系统分析。研究通过数据聚合、空间数据构建、多维度地图可视化等技术手段，生成了全时段站点客流热力图、分时段客流空间对比图、工作日与周末客流差异图、TOP50 OD客流流向图等静态可视化成果，并构建了可交互的网页地图系统。研究发现：上海地铁客流呈现显著的"中心集聚、轴向辐射"空间格局，早晚高峰具有明显的潮汐式通勤特征，工作日与周末客流在空间分布上存在系统性差异，OD客流高度集中在少数主要通勤走廊上。本研究的可视化成果可为城市交通规划、地铁运营调度和乘客出行引导提供直观的数据支撑。

**关键词**：上海地铁；客流分析；空间可视化；热力图；OD流向图；出行模式

## 1 研究背景与意义

### 1.1 研究背景

地铁作为城市公共交通的骨干系统，在缓解城市交通拥堵、减少碳排放、促进城市空间结构优化等方面发挥着不可替代的作用。上海作为中国人口最多、经济最发达的城市之一，其地铁网络规模和客运量均位居世界前列。截至2017年，上海地铁已拥有十余条运营线路、数百个站点，日均客运量超过千万人次，是城市居民日常出行的主要方式。

然而，庞大的客流也给地铁系统的运营管理带来了巨大挑战。高峰时段部分线路和站点过度拥挤、客流时空分布不均、新城区与中心城区之间通勤压力大等问题日益突出。要科学有效地应对这些问题，首先需要深入理解地铁客流的时空分布规律和乘客的出行模式。

传统的客流分析多以统计表格和二维图表为主，虽然能够反映客流的数量特征，但难以直观呈现客流的空间分布格局和时空演变规律。空间可视化技术通过将客流数据与地理信息叠加，以热力图、流向图、交互地图等形式直观展示客流的空间分布特征，为客流分析提供了更具洞察力的工具。

### 1.2 研究意义

本研究的意义主要体现在以下几个方面：

**理论意义**：通过对上海地铁客流数据的多维度空间可视化分析，丰富了城市轨道交通客流分析的方法体系，验证了空间可视化技术在揭示城市居民出行模式方面的有效性，为相关领域的研究提供了可参考的案例。

**实践意义**：研究成果直观呈现了上海地铁客流的空间分布规律、高峰时段客流集聚特征、工作日与周末客流差异以及主要通勤走廊，可为地铁运营部门的列车调度、站点管理、客流引导提供决策参考，也可为城市规划部门的线网优化和土地利用规划提供数据支撑。

**课程实践意义**：作为《软件开发实践1》课程项目的组成部分，本研究完整经历了从数据获取、预处理、可视化开发到成果分析的全流程，锻炼了数据处理、Python编程、空间分析和可视化开发等实践能力。

## 2 数据来源与预处理

### 2.1 数据来源

本研究使用的原始数据来自MetroFlow公开数据集（Sun et al., 2025），该数据集收录了2017年5月1日至8月31日共4个月的上海地铁智能卡刷卡记录，包含以下核心数据文件：

- **刷卡记录数据**：超过7亿条智能卡进出站记录，包含卡号、进站站点、出站站点、进出站时间等字段
- **站点属性数据**：302个地铁站的基础信息，包括站点ID、站点名称、所属线路、经纬度坐标、相邻站点等
- **天气辅助数据**：小时级的天气信息，包括温度、湿度、降水、天气状况等
- **工作日历数据**：每日的工作日/休息日标记，用于区分工作日和周末客流

数据集的时间跨度覆盖了春末至夏初的完整季节周期，包含了工作日、周末、节假日等多种日期类型，能够较为全面地反映上海地铁客流的常态特征。

### 2.2 数据预处理

本研究使用的数据经过分工1（数据工程）的系统预处理，主要处理流程包括：

1. **数据清洗**：剔除异常记录（如同站进出、出行时长超出合理范围、逻辑错误数据等），补全缺失字段
2. **行程识别**：基于刷卡时间和站点信息，识别完整的出行行程（OD对）
3. **流量提取**：按10分钟时间粒度统计各站点的进站量、出站量，以及各OD对的客流量
4. **数据聚合**：在10分钟粒度数据基础上，进一步聚合出全天、早高峰（7:00–9:00）、晚高峰（17:00–19:00）、工作日日均、周末日均等多维度客流指标

经过预处理后，本研究直接使用以下两个聚合数据表进行可视化分析：

- **station_flow_agg.csv**：站点级多维度客流聚合表，包含302个站点的全天总客流、早高峰客流、晚高峰客流、工作日日均客流、周末日均客流等指标
- **od_flow_agg.csv**：OD客流聚合表，按客流量降序取TOP50的起终点对，包含起终点站点ID、名称、经纬度和客流量

## 3 研究方法与技术路线

### 3.1 技术选型

本研究采用Python生态下的空间数据处理与可视化工具链，主要技术栈包括：

| 技术/库 | 用途 |
|---------|------|
| pandas | 数据读取、清洗与聚合计算 |
| geopandas | 空间数据处理与分析 |
| shapely | 空间几何对象操作（点、线、面） |
| matplotlib | 静态图表绘制与可视化渲染 |
| contextily | 在线底图瓦片加载与叠加 |
| pyproj | 坐标系转换 |
| folium | 交互式网页地图构建 |

### 3.2 坐标系处理

空间可视化的关键前提是坐标系的统一。本研究涉及两种坐标系：

- **WGS84（EPSG:4326）**：原始站点经纬度数据使用的坐标系，也是GPS设备的标准坐标系
- **Web墨卡托（EPSG:3857）**：在线地图瓦片通用的投影坐标系，用于底图叠加

在可视化过程中，站点数据以WGS84存储，叠加底图时自动转换为Web墨卡托投影，确保站点位置与底图精确对齐。

### 3.3 底图选择

本研究选用高德地图浅色瓦片作为底图，主要考虑以下因素：

1. **中文标注**：高德底图提供完整的中文地名和道路标注，适合国内城市分析
2. **地铁线路**：高德底图自带清晰的地铁线路和站点标注，无需额外加载线路矢量数据
3. **浅色风格**：浅色底图与热力图的暖色配色形成良好对比，突出客流信息
4. **访问稳定**：高德地图瓦片服务在国内访问速度快、稳定性高

### 3.4 可视化方法

本研究采用多种可视化方法从不同维度呈现客流特征：

1. **点大小+颜色双编码热力图**：用圆点的大小和颜色深浅同时映射客流量级，直观反映站点客流的空间分布差异
2. **多时段对比组图**：将不同时段的客流热力图排列为组图，统一色阶便于横向比较，揭示客流的时空演变规律
3. **双向色阶差值图**：用红色-蓝色双向色阶表示工作日与周末的客流差值，直观识别通勤主导型和休闲主导型站点
4. **贝塞尔弧线OD流向图**：用二次贝塞尔曲线连接起终点，弧线粗细映射客流量，避免直线重叠，清晰展示城市主要客流走廊
5. **交互式网页地图**：基于Folium构建可缩放、可点击查询的交互地图，支持用户自主探索数据

### 3.5 技术路线

本研究的整体技术路线如下：

```
原始刷卡数据 → 数据清洗与预处理（分工1）
    ↓

┌────────────┬────────────┬────────────┬────────────┐

└────────────┴────────────┴────────────┴────────────┘
    ↓                        ↓
```

## 4 可视化成果与分析

### 4.1 全时段站点客流空间分布

**图3-1 全时段站点客流热力图**展示了2017年5–8月期间上海地铁302个站点全天总客流的空间分布格局。图中每个圆点代表一个地铁站，圆点的大小和颜色深浅（从浅黄色到深红色）共同映射该站的全天总客流量级。

从图中可以清晰观察到以下空间分布特征：

**（1）中心集聚特征显著**

客流高度集中在上海市中心城区（大致为内环以内及内外环之间的核心区域），形成了以人民广场、静安寺、陕西南路、徐家汇等为核心的客流高密度集聚区。这些区域是上海的商业中心、商务中心和交通枢纽，土地利用强度高，就业岗位密集，吸引了大量的通勤和消费客流。

**（2）轴向辐射格局明显**

客流从中心城区沿地铁线路向郊区呈轴向辐射状递减。沿着1号线（南北向）、2号线（东西向）、9号线（西南-东北向）等主要干线，客流从市中心向郊区逐渐降低，形成了明显的"廊道效应"。这表明地铁线路对城市客流的空间分布具有强烈的引导和塑造作用。

**（3）枢纽站点客流突出**

人民广场站（1号线、2号线、8号线换乘）、静安寺站（2号线、7号线换乘）、陕西南路站（1号线、10号线、12号线换乘）等大型换乘枢纽站的客流显著高于周边普通站点。这些站点作为地铁网络的关键节点，承担了大量的换乘客流，是整个地铁系统客流的"压舱石"。

**（4）郊区站点客流分化**

郊区站点的客流呈现明显的分化特征。部分郊区新城的核心站点（如松江新城、嘉定新城、临港大道等）客流相对较高，成为郊区的客流次级中心；而大部分远郊站点客流较低，尤其是线路末端站点，客流量级仅为市中心核心站点的十分之一甚至更低。

### 4.2 分时段客流时空演变

**图3-2 分时段客流空间对比图**以四宫格的形式，分别展示了早高峰（7:00–9:00）、晚高峰（17:00–19:00）、工作日日均、周末日均四个时段的客流空间分布。四张子图使用统一的色阶，便于横向比较不同时段的客流差异。

通过对比分析，可以发现以下时空演变规律：

**（1）早高峰：郊区→市中心的向心集聚**

早高峰时段，客流呈现明显的向心集聚特征。郊区站点（尤其是郊区新城的居住型站点）的进站客流显著增加，大量居住在郊区的乘客通过地铁向市中心商务区通勤。与此同时，市中心的商务型站点（如陆家嘴、人民广场、静安寺等）的到达客流达到峰值。整个地铁网络呈现出"郊区涌出、市中心涌入"的潮汐式客流特征。

**（2）晚高峰：市中心→郊区的离心扩散**

晚高峰时段的客流方向与早高峰恰好相反，呈现离心扩散特征。市中心商务区站点的出站客流（对应下班出发）达到峰值，而郊区居住型站点的到达客流显著增加。乘客从工作地返回居住地，形成"市中心涌出、郊区涌入"的反向潮汐。

**（3）高峰与平峰的空间差异**

对比工作日日均和早晚高峰的客流分布，可以发现高峰时段客流的空间集中度更高。早高峰时，客流主要集中在通勤走廊上（如9号线松江段、11号线嘉定段、2号线张江段等），而平峰时段客流的空间分布相对均匀，商业、休闲类站点的客流占比上升。

**（4）周末客流的空间重构**

周末日均的客流空间分布与工作日存在明显差异。周末时，市中心的商业休闲类站点（如南京路、淮海路、徐家汇、迪士尼等）的客流占比显著上升，而商务办公区站点的客流明显下降。郊区的旅游景点类站点（如野生动物园、迪士尼等）在周末的客流也有所增加。这反映了周末出行目的从"通勤"向"休闲消费"的转变。

### 4.3 工作日与周末客流差异

**图3-3 工作日与周末客流差异图**通过计算工作日日均客流减去周末日均客流的差值，用双向色阶（红色表示工作日客流更高，蓝色表示周末客流更高）直观展示了两类日期的客流空间差异。圆点大小表示差值的绝对值。

从图中可以识别出两类典型站点：

**（1）通勤主导型站点（红色区域）**

工作日客流显著高于周末的站点主要集中在：

- **市中心商务区**：如陆家嘴、人民广场、静安寺、南京西路等区域，这些区域聚集了大量写字楼和企业，工作日通勤客流巨大，而周末办公人群减少，客流明显下降
- **产业园区周边**：如张江高科技园区、漕河泾开发区等，工作日有大量上班族通勤，周末客流锐减
- **郊区居住新城**：如松江新城、嘉定新城、临港新城等，工作日有大量居民外出通勤，周末居民出行相对减少或出行模式改变

这些站点的客流高度依赖工作日的通勤出行，是城市通勤系统的重要组成部分。

**（2）休闲主导型站点（蓝色区域）**

周末客流高于工作日的站点主要包括：

- **商业中心站点**：如南京路、淮海路、徐家汇、五角场等，周末购物休闲人群增加
- **旅游景点站点**：如迪士尼、野生动物园、豫园、外滩等，周末游客数量显著增加
- **文化体育设施周边**：如博物馆、体育馆、公园等周边站点，周末休闲客流上升

这些站点的客流更多地受休闲、娱乐、旅游等非通勤出行驱动，周末客流表现更为活跃。

**（3）差异的空间格局**

从整体空间格局来看，工作日-周末客流差异呈现出"商务红、休闲蓝"的空间分异。市中心的商务区以红色为主，而商业休闲区和远郊旅游景点以蓝色为主。这种差异本质上反映了城市土地利用的功能分区——就业集中区与休闲消费集中区在空间上的分离。

### 4.4 OD客流流向与通勤走廊

**图3-4 全时段TOP50 OD客流流向图**展示了客流量最大的50对起终点（OD对）之间的客流流向。图中用贝塞尔弧线连接起点和终点，弧线的粗细对应客流量级，颜色从浅黄到深红表示客流从小到大。背景为高德浅色底图，站点以深灰色圆点表示。

通过分析TOP50 OD对的空间分布，可以发现以下特征：

**（1）短距离OD占主导**

TOP50 OD对中，相当一部分是空间距离较近的相邻站点或同线路相邻区段。例如，龙华中路↔上海体育场、上海室内体育场↔宜山路、虹桥路↔镇坪路等OD对的客流量都很大。这反映了地铁出行中短距离通勤和换乘的高频特征——大量乘客的出行距离集中在几站到十几站之间。

**（2）换乘枢纽是客流集散核心**

人民广场、宜山路、上海体育场、镇坪路等大型换乘站在TOP50 OD对中频繁出现，既是重要的起点也是重要的终点。这些站点作为地铁网络的枢纽节点，承担了大量的客流集散和换乘功能，是整个OD网络的核心节点。

**（3）主要通勤走廊清晰可辨**

虽然TOP50 OD对以短距离为主，但仍能识别出几条主要的长距离通勤走廊：

- **西南方向**：松江体育中心→上海体育场/宜山路方向，反映了松江新城与中心城区之间的通勤联系
- **西北方向**：嘉定相关站点→市中心方向，反映了嘉定新城与中心城区的通勤联系
- **东南方向**：临港大道/惠南东→市中心方向，反映了临港新城与中心城区的远距离通勤联系

这些长距离通勤走廊连接了郊区新城和中心城区，是城市跨区域通勤的主要通道，也是高峰时段地铁拥挤的主要来源。

**（4）OD客流的不对称性**

部分OD对存在明显的方向不对称性，即A→B的客流量与B→A的客流量存在差异。例如，早高峰时郊区→市中心的客流量大于反向，晚高峰则相反。这种不对称性正是潮汐式通勤的直接体现。

### 4.5 交互式可视化系统

除了静态可视化图片，本研究还基于Folium构建了**上海地铁客流交互地图**（HTML格式），用户可以直接在浏览器中打开使用。该交互系统具有以下功能：

**（1）地图基础操作**：支持地图的缩放、拖拽、平移等基础操作，用户可以自由浏览整个上海地铁网络，也可以放大到特定区域查看细节。

**（2）站点客流可视化**：每个站点以圆形标记表示，圆的半径映射该站的全天总客流量级，颜色统一为红色系，直观反映站点的客流规模差异。

**（3）点击查询详情**：点击任意站点，会弹出信息窗口，显示该站点的名称、全天总客流、早高峰客流、晚高峰客流等详细数据，方便用户查询特定站点的客流信息。

**（4）底图切换**：使用CartoDB浅色底图，风格简洁，突出站点信息。

交互地图的优势在于将数据探索的主动权交给用户，用户可以根据自己的兴趣和需求，自由缩放、点击查询，发现静态图表中可能被忽略的细节和规律。

## 5 主要发现与讨论

### 5.1 客流空间格局：中心集聚与轴向辐射

上海地铁客流的空间分布呈现出典型的"中心集聚、轴向辐射"格局。中心城区由于高度集中的就业岗位、商业设施和交通枢纽，成为客流的核心集聚区；而地铁线路则像一条条"客流走廊"，将郊区与中心城区连接起来，客流沿线路呈轴向递减。

这种空间格局本质上是城市空间结构的反映。上海作为单中心结构的特大城市，中心城区仍然是城市功能的核心，郊区新城虽然发展迅速，但在就业岗位和公共服务供给方面与中心城区仍有较大差距，导致大量居民需要跨区域通勤。这种"居住在郊区、就业在中心"的空间错位，是地铁客流潮汐式特征的根本原因。

### 5.2 时间特征：潮汐式通勤与周末重构

客流的时间特征表现为明显的"工作日潮汐、周末重构"模式。工作日早晚高峰，客流在郊区与中心城区之间呈潮汐式往返，方向相反但量级相当；而到了周末，通勤出行大幅减少，休闲、购物、旅游等出行目的占比上升，客流的空间分布也随之发生重构——商务区客流下降，商业休闲区和旅游景点客流上升。

这种时间特征提示地铁运营部门在不同时段应采取差异化的运营策略：工作日高峰时段应重点保障通勤走廊的运力供给，增加列车班次、优化换乘组织；而周末则应重点关注商业中心和旅游景点周边站点的客流疏导，做好大客流应对预案。

### 5.3 站点类型分化：通勤型与休闲型

通过工作日与周末客流差异分析，可以将地铁站点大致分为通勤主导型和休闲主导型两类。通勤主导型站点主要分布在商务区、产业园区和郊区居住新城，客流高度依赖工作日通勤；休闲主导型站点主要分布在商业中心、旅游景点和文化设施周边，周末客流更为活跃。

站点类型的分化对于站点周边的土地利用规划和商业开发具有参考意义。对于通勤主导型站点，周边应优先保障通勤设施（如自行车停放点、公交接驳站、早餐网点等）；对于休闲主导型站点，周边则可重点发展商业、娱乐、餐饮等业态，提升站点的综合服务能力。

### 5.4 OD网络：枢纽核心与走廊支撑

OD客流分析表明，上海地铁的OD网络呈现出"枢纽核心、走廊支撑"的结构特征。大型换乘枢纽站是OD网络的核心节点，承担了大量的客流集散；而主要地铁线路则构成了客流运输的走廊，支撑着城市跨区域的通勤联系。

TOP50 OD对中短距离出行占主导，说明地铁出行的平均距离并不长，大部分乘客的出行集中在局部区域。但少数长距离通勤走廊（如松江→市中心、嘉定→市中心、临港→市中心）虽然OD对数量不多，但客流量大、距离长，是地铁网络中最"沉重"的客流，也是高峰拥挤的主要来源。对于这些长距离通勤走廊，应重点关注其运力配置和拥挤治理。

### 5.5 可视化方法的有效性

本研究的实践表明，空间可视化技术在地铁客流分析中具有独特的优势：

1. **直观性**：热力图、流向图等可视化形式能够将抽象的客流数据转化为直观的空间图像，让人一眼就能看出客流的分布规律
2. **洞察力**：通过多维度、多时相的可视化对比，能够发现单纯统计分析难以察觉的空间模式和时空演变规律
3. **交互性**：交互式地图允许用户自主探索数据，满足不同用户的个性化分析需求
4. **传播性**：可视化成果易于理解和传播，适合用于报告展示、决策汇报和公众沟通

当然，空间可视化也有其局限性。可视化主要用于揭示"是什么"的模式，对于"为什么"的因果解释还需要结合其他分析方法（如统计建模、问卷调查等）进行深入探讨。

## 6 结论与展望

### 6.1 研究结论

本研究基于2017年5–8月上海地铁刷卡数据，从空间可视化视角对上海地铁客流的时空分布特征和乘客出行模式进行了系统分析，主要得出以下结论：

1. **空间格局**：上海地铁客流呈现"中心集聚、轴向辐射"的空间格局，中心城区高度集聚，沿地铁线路向郊区轴向递减，换乘枢纽站客流突出。

2. **时间特征**：客流具有明显的潮汐式通勤特征，早高峰向心集聚、晚高峰离心扩散；周末客流空间分布发生重构，商务型站点客流下降，休闲型站点客流上升。

3. **站点分化**：站点可分为通勤主导型和休闲主导型两类，前者集中在商务区、产业园区和郊区新城，后者集中在商业中心和旅游景点，反映了城市功能分区的空间差异。

4. **OD网络**：OD客流以短距离出行为主，大型换乘枢纽是网络核心节点；少数长距离通勤走廊（松江、嘉定、临港→市中心）承载了大量跨区域通勤客流，是高峰拥挤的主要来源。

5. **方法验证**：空间可视化技术在揭示地铁客流时空规律方面具有直观性、洞察力和交互性等优势，是城市交通客流分析的有效工具。

### 6.2 研究不足

本研究也存在一些不足之处：

1. **数据时间限制**：数据仅覆盖2017年5–8月，未能反映不同年份和季节的客流变化，也无法体现近年来上海地铁网络扩展（如新线路开通）对客流格局的影响。

2. **可视化维度有限**：本研究主要聚焦于站点客流和OD流向的空间可视化，未能将天气因素（温度、降水等）与客流变化进行联动可视化，也未深入挖掘乘客个体的出行链特征。

3. **算法分析不足**：作为空间可视化分工，本研究主要侧重于可视化呈现，未使用聚类、预测等机器学习算法对客流进行深度挖掘，这部分内容由分工5的同学完成。

4. **交互功能待丰富**：当前的交互地图功能较为基础，仅支持站点点击查询，尚未实现时段切换、OD查询、图层控制等更丰富的交互功能。

### 6.3 未来展望

基于本研究的成果和不足，未来可以从以下方向进一步拓展：

1. **多源数据融合**：将地铁刷卡数据与公交刷卡数据、共享单车数据、手机信令数据等多源数据融合，构建更完整的城市居民出行画像。

2. **动态可视化**：开发带时间轴的动态客流可视化系统，实现客流时空演变的动画播放，更直观地展示一天内客流的流动过程。

3. **三维可视化**：结合建筑高度、人口密度等数据，构建三维客流可视化模型，更真实地反映城市空间与客流的关系。

4. **实时可视化**：对接地铁实时客流API，构建实时客流监控可视化大屏，为地铁运营调度提供实时决策支持。

5. **预测可视化**：结合机器学习预测算法，将客流预测结果以可视化方式呈现，实现"历史-现状-预测"一体化的客流分析平台。
